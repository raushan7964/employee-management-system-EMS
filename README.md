# Employee Management System (EMS)

A comprehensive Employee Management System built with React and Vite, designed to streamline task management, employee tracking, and administrative workflows.

## Features

- **Admin Dashboard**: Centralized hub for managers to oversee employee performance and task status.
- **Task Management**: Create, assign, and track tasks with efficient workflows.
- **Employee Task Distribution**: Visual breakdown of task status (New, Active, Completed, Failed) per employee.
- **Responsive Design**: Built with Tailwind CSS for a seamless experience across devices.

## Tech Stack

- **Frontend**: React, Vite
- **Styling**: Tailwind CSS
- **Icons**: React Icons
- **Linting**: ESLint

## Getting Started

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```

## Development

This project uses Vite for fast development responsiveness.
- `npm run dev`: Start dev server
- `npm run build`: Build for production
- `npm run preview`: Preview production build
